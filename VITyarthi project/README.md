# 🔨 Whack-a-Mole Game

A classic arcade-style Whack-a-Mole game built using Python. Test your reaction speed and hand-eye coordination by whacking moles before they disappear!

---

## 📖 Overview

This project is a desktop implementation of the traditional Whack-a-Mole arcade game. The objective is simple:A mole randomly pops up from various holes on the screen, and the player must click to whack them and earn SCORE within a set time limit. 

This project was built to demonstrate core programming concepts in Python, including graphical user interface (GUI) event handling, game loop mechanics, timing functions, and score tracking.

---

## ✨ Features

- **Interactive Gameplay:** Mole appears and disappears at randomized positions.
- **Timer & Score Tracking:** Real-time dynamic display of your current score and remaining game time.
- **Difficulty Scaling** The more the players scores the faster the mole gets.
  

---

## 🛠️ Tools & Technologies Used

- **Programming Language:** Python 3.x
- **Libraries & Modules:**
  - `random` - For randomized mole appearances
  - `Tkinter` - For GUI and interaction with the mole
  - `logic`- Dictates the game logic of randomiziation and object placement(User defined)
  - `Config`- Contains variables which can be modified to change certain aspects of the games(User defined)
